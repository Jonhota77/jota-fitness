## 📲 Cómo instalar

1. Descarga el archivo `.apk` desde el celular.
2. Ábrelo desde las notificaciones o desde la carpeta **Descargas**.
3. Si el celular dice *"Por seguridad, tu teléfono no puede instalar apps de fuentes desconocidas"*, toca **Configuración** y activa **Permitir de esta fuente**.
4. Toca **Instalar** y luego **Abrir**.

> Si Google Play Protect muestra un aviso, toca **Más detalles → Instalar de todas formas**. Sale porque la app no se descarga de la Play Store.

**Para actualizar:** descarga la versión nueva e instálala encima. No necesitas desinstalar y no pierdes tus datos.
